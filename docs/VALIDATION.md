# 검증 기록

검증일: 2026-10-07. 로컬 macOS에서 Quarto 1.6.42, R, XeLaTeX/TeX Live 2025를 사용했습니다.

## 예제 출력

| 프로필 | 결과 | 페이지 수 |
|---|---|---|
| ko-master | PDF 생성 및 내용 검증 통과 | 15 |
| ko-phd | PDF 생성 및 내용 검증 통과 | 15 |
| en-master | PDF 생성 및 내용 검증 통과 | 14 |
| en-phd | PDF 생성 및 내용 검증 통과 | 14 |

모든 프로필을 `quarto render --profile 프로필명`으로 출력했습니다. PDF를 이미지로 렌더링해 전체 페이지를 확인했으며 표지·인준지·본문·초록의 잘림과 겹침을 점검했습니다.

자동으로 확인한 항목:

- 19×26cm 페이지 크기.
- 표제지 한 페이지, 인준지 한 페이지, 석사 3명/박사 5명.
- 세 종류 날짜와 저자 정보.
- 앞쪽 초록과 목차, 참고문헌·부록·뒤쪽 초록의 순서.
- 서론이 제1장/Chapter 1이며 본문 쪽수가 1에서 시작.
- 빈 index.qmd 때문에 불필요한 장이나 빈 페이지가 생기지 않음.
- R 계산 결과: 관측값 50개, 평균 속도 15.4, 평균 제동 거리 42.98, 회귀계수 3.932.
- 표·그림·수식의 교차참조와 참고문헌 출력.
- PDF 저자 메타데이터가 `thesis.yml`의 이름과 일치.

## 시작 프로젝트 검증

로컬 템플릿 ZIP에 대해 `quarto use template /경로/template.zip --no-prompt`를 실행했습니다. 확장 기능, QMD, 설정 파일, 글꼴이 새 폴더에 설치되는 것을 확인했습니다. 한글과 공백이 들어간 폴더에서 캐시 없이 `quarto render --quiet`를 실행하여 기본 국문 석사 PDF를 생성했습니다.

공개 저장소 `statisticsplaybook/snu-thesis-quarto`에서 `quarto use template statisticsplaybook/snu-thesis-quarto --no-prompt`로 새 프로젝트를 만들었습니다. 원격 다운로드·확장 및 글꼴 복사·기본 국문 석사 PDF 출력과 제공 검증 스크립트 통과(15쪽)를 확인했습니다. PDF 전체 페이지도 이미지로 확인했습니다. 이 검증은 현재 macOS의 새 프로젝트 폴더에서 수행했으며, 운영체제 전체를 새로 설치한 환경의 검증은 아닙니다.

GitHub Actions의 세 운영체제·네 프로필 검증은 [실행 목록](https://github.com/statisticsplaybook/snu-thesis-quarto/actions)에서 확인합니다. 저장소 공개 시 자동 검증 실행을 시작했으며 결과는 실행별 상태를 따릅니다.

## 입력 오류 검증

임시 메타데이터를 사용해 잘못된 월(2027-13), 석사 위원 수 부족, 지도교수의 위원장 지정, 주요어 개수 초과를 입력했습니다. 각각 이유를 표시하고 출력을 중단하는 것을 확인했습니다. 초록에 R 실행 청크를 넣었을 때도 지원하지 않는 위치임을 안내하고 중단합니다.

## 긴 제목과 선택 항목

새 프로젝트에 긴 국문·영문 제목, &, %, 밑줄(_), 긴 학과·전공명을 입력하고 국문 박사 PDF를 출력했습니다. 부제는 생략하고 감사문을 추가했습니다. 제목이 표제지와 인준지에 완전히 표시되고, 박사 위원 5명과 인준 내용이 한 페이지에 들어가는 것을 텍스트와 이미지로 확인했습니다. 감사문은 뒤쪽 초록 다음에 출력됩니다. 임의로 더 긴 제목이나 여러 지도교수 등 검증하지 않은 구성은 별도 확인이 필요합니다.

## 운영체제 검증 범위

macOS 로컬 실행과 공개 저장소에서 받은 시작 프로젝트 출력은 완료했습니다. Windows·Linux·macOS의 네 프로필은 `.github/workflows/render.yml`로 자동 검증하며, 운영체제별 통과 여부는 GitHub Actions의 해당 실행 결과를 확인합니다. 학생의 실제 연구 코드에 필요한 R 패키지는 별도 관리가 필요합니다.

## 환경에서 발견한 사항

- 설치된 R 패키지 조합에서 `xfun::attr()` 사용 중단 안내가 출력되었으나 knitr 실행과 PDF 생성은 완료되었습니다. 본 프로젝트 코드에서 해당 함수를 호출하지 않습니다.
- 처음에는 Babel의 한국어 하이픈 패키지 자동 설치가 기존 TeX Live 2025와 2026 패키지 서버 사이의 버전 차이로 실패했습니다. 한글 조판은 ko.TeX, 영문 하이픈은 Babel English로 분리하여 해결했습니다. 최종 출력은 자동 설치를 끄는 임시 옵션 없이 기본 명령으로 성공했습니다. 한국어 인용·교차참조의 언어는 `lang: ko-KR`로 유지됩니다.
- 원본 국문 LaTeX 저장소의 라이선스 불명확성과 글꼴 경로 의존성 때문에 원본 코드를 재배포하지 않고 공통 서식을 새로 구현했습니다.

## 유지보수자가 다시 검증하기

Python은 일반 학생의 PDF 출력에 필요하지 않습니다. 유지보수용 PDF 검사에만 사용합니다.

```bash
python -m pip install pypdf PyYAML
quarto render --profile ko-master
python scripts/verify.py output/pdf/snu-thesis-ko-master.pdf --profile ko-master
```

나머지 프로필에도 같은 방식으로 적용합니다. 이 스크립트는 제공한 예제의 수치·이름·날짜를 검증하는 도구이므로 학생이 내용을 바꾼 실제 논문의 일반 검증 도구는 아닙니다.

학교 Word/HWP와의 비교는 문서 구성과 필드 중심입니다. 글꼴·쪽 배치의 픽셀 단위 동일성을 보장하거나 학교의 승인 여부를 검증한 것은 아닙니다. 짧은 예제 초록은 제출용 분량 요건을 충족하기 위한 샘플이 아닙니다.
